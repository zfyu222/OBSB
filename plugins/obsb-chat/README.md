# OBSB AI 管家 0.2.3

Obsidian 原生聊天客户端，连接已经部署的 NAS OpenCode 2.x。AI、模型密钥、Skills、AI 笔记编辑和完整整理仍在服务器运行；插件显示服务器会话与回答、打开本地 Markdown 引用，并提供不依赖服务器的一键记录入口。Windows 使用右侧栏，Android 使用主区域标签页；旧移动侧栏在再次运行“打开 AI 管家”时自动转换。未启动本地 Agent，也没有新增服务容器。

## 功能

- AI 文件修改记录：读取 OpenCode 工具结果中的 `state.metadata.files`，在对应消息下显示文件路径、增删行数和带行号的逐行差异。短差异默认展开，长差异默认折叠；每个文件最多展示前 500 行，服务器截断或缺少 patch 时明确提示到 OpenCode 页面查看。历史消息也使用同一展示，修改内容按字面文本渲染。此项自 0.2.3 起提供。

- 一键记录：桌面 URI、侧边工具栏铅笔图标或命令“一键记录到 Inbox”直接打开多行记录框。仅需输入正文和点击保存，自动创建 `InBox/灵感-日期-时间-毫秒.md`，同名时增加序号，不覆盖旧笔记。保存后关闭记录框，不打开新文件；普通 Enter 换行，Ctrl/⌘+Enter 可保存。
- 草稿在输入停止约 250ms 后暂存到当前设备插件配置，关闭时再次保存；重启后可恢复，保存失败保留内容，已写入笔记但草稿清理失败时重试识别原文件，避免重复创建。草稿不参与 LiveSync。记录不调用模型、不请求 NAS、不处理正文中的 URL 或附件；后续同步由原 LiveSync 负责。

- AI 追问直接显示为表单，支持单选、多选、自定义回答、文本、数字和是/否；可一次回答多道问题，也可取消提问。轮询刷新保留未提交答案，失败保留输入；其他设备已处理的表单会从面板移除。外部字段等未支持类型提示回 OpenCode 网页继续，不伪造答案。
- 会话栏“管理”读取当前项目全部分页，支持搜索标题、勾选删除及“全选当前项目”；删除前显示具体标题并确认。运行中的对话及已识别的运行中子对话须先停止。删除的是服务器历史，其他设备也会生效；不会撤销笔记修改。服务器可能连带删除关联子对话。批量操作部分失败时保留实际成功结果并重新读取列表。
- “附加笔记 / 命令”中的“清空当前对话”会确认后删除当前服务器对话并创建空白新对话。清空所有当前项目对话可在“管理”中全选后删除；仅清理聊天记录，不操作知识 Markdown。
- “压缩历史”按钮或 `/compact` 调用服务器专用压缩接口，生成后续模型上下文的摘要，保留原聊天记录。当前对话运行中或等待表单回答时先完成/停止操作再压缩。压缩使用现有服务器模型，可能产生模型调用费用；不接受参数或附加笔记上下文。
- 命令列表动态读取服务器命令并展示说明，当前 NAS 2.0.7 返回 `/init`、`/review`、`/run-nightly`，插件另提供 `/compact`。选择命令后点击发送；也可输入命令及参数。命令能力随服务器配置变化，不把终端快捷键或所有 CLI 子命令当成聊天命令。

- 手机使用紧凑布局，顶部按钮和会话选择保持单行；“附加笔记 / 命令”默认折叠，点击展开后使用当前笔记、选中文字及服务器命令。输入框与发送按钮并排，输入框随内容增高并限制高度；空闲时不展示停止按钮，优先为聊天记录保留空间。桌面附件操作保持展开。

- 从服务器读取 `/workspace` 会话，继续网页或其他设备已有的对话；支持更多会话和更早消息分页。
- 新对话不指定固定时间标题，交给 OpenCode 根据开头的对话自动生成主题名称；自动刷新同步当前会话标题，保留已加载的历史会话和当前选择。标题请求失败不影响消息显示。已有旧标题不批量重写，服务器生成失败时保留默认名称。
- 原生 Markdown 回答；点击 wikilink 的标题/块引用在当前 vault 打开笔记。也识别内联代码中的 `Raw/…md`、`vault/Raw/…md` 等路径，以及 Markdown 链接中的 `/workspace/vault/…md`。
- 聊天正文允许选中文字复制；每条消息提供“复制”按钮，复制原始 Markdown（保留链接），不包含工具状态或思考内容。空闲自动刷新不再重排未变化的消息，以免打断文字选择。
- 尚未同步到本机的笔记显示提示，不创建空笔记；服务器路径转换为 vault 相对路径。
- SSE 增量显示回答；若 WebView/CORS 不支持流式请求，自动改为约 1.5 秒获取运行中回答、8 秒检查空闲会话。回到前台或网络恢复时重新连接；不承诺 Android 后台执行。
- 当前笔记作为路径上下文，不自动上传整篇正文；选中文字作为用户材料发送。笔记读取以服务器已同步内容为准。
- `/run-nightly` 使用服务器正式命令接口，执行原有完整整理流程；其他服务器命令也可选择。附加上下文与命令不混合提交。
- 操作请求显示“允许这一次”和“拒绝”，遵循现有 OpenCode 配置，不另行自动授权；支持停止当前执行。

## 构建与安装

推荐通过 BRAT 安装：在 Obsidian 社区安装并启用 BRAT，在其设置中添加 `https://github.com/zfyu222/OBSB`，选择最新版本。安装和更新不需要解压或复制文件；详见 [工程首页](../../README.md)。当前尚未上架官方社区目录。

在本目录运行 `npm ci`、`npm run check`、`npm test`、`npm run build`。构建产物为 `dist/obsb-chat/{main.js,manifest.json,styles.css}`。依赖只用于构建/测试；运行时仅依赖 Obsidian，不需要设备安装 Node.js。

Windows 可从工程根目录执行：

```powershell
pwsh -File plugins/obsb-chat/scripts/install.ps1 -VaultPath H:\obsb
```

脚本只复制三个插件程序文件，不自动启用插件、不覆盖 `data.json`；升级前把原程序备份到工程 `artifacts/`。启用方式：Obsidian 设置 → 社区插件 → 已安装插件 → OBSB AI 管家。安装时可先关闭 Obsidian；已打开时重新启动以加载插件。

Android 推荐使用 BRAT 安装和更新，更新后重新启用插件并运行“打开 AI 管家”。手动安装时，也可把安装包中的 `obsb-chat` 文件夹复制到手机仓库的 `.obsidian/plugins/`。本项目关闭了隐藏配置同步，所以两台设备分别安装和填写连接设置。

## Android 桌面“一键记录”

1. 更新插件后，在 **设置 → OBSB AI 管家 → 一键记录 → 桌面链接** 点击“复制”。也可运行命令“复制一键记录桌面链接”。链接会自动带上当前仓库名称并编码，例如 `obsidian://obsb-capture?vault=obsb`；不要使用其他设备不同名称仓库的链接。
2. 用手机桌面支持的自定义链接/URL 快捷方式功能创建入口，名称填“一键记录”，目标粘贴完整链接。若桌面不支持自定义协议，可使用支持 URI/Intent 快捷方式的工具；这是一次性配置辅助，不是新的记录应用。本插件无法直接在 Android 桌面固定图标，也不提供原生系统小组件。
3. 点击桌面入口，Obsidian 切到前台并打开记录框；键盘聚焦会主动请求，是否立即显示需实际 Android WebView/输入法验证。首次或冷启动要等待仓库和插件加载，多次点击不重复打开弹窗。
4. 输入正文，点击“保存”。成功后弹窗关闭，原笔记页面保留；返回桌面按 Home。点击“稍后再写”或系统返回关闭弹窗会保留草稿。

记录可离线使用，不需填写 AI 连接信息。InBox 中新笔记会在 Obsidian/LiveSync 工作且网络可用时同步；不承诺关闭 Obsidian 后仍后台即时同步。未保存的草稿只在当前设备，不会出现在其他设备。移动端冷启动 URI 的投递、桌面入口和键盘体验仍须实机验收。

## Android 桌面“一键打开 AI 管家”

在插件设置 → “一键打开 AI 管家”复制桌面链接，用与“一键记录”相同的桌面快捷方式功能配置，名称设为“OBSB AI 管家”。也可运行命令“复制 AI 管家桌面链接”。链接格式为 `obsidian://obsb-chat?vault=编码后的仓库名`，不含连接密码。

点击后直接打开当前仓库的聊天面板，复用已有聊天；不新建对话或自动发送消息。冷启动等待 Obsidian 加载，连续点击合并处理。Android 使用主区域标签页；阅读或发送 AI 消息仍需服务器连接。桌面配置和冷启动投递需实机验收。

## AI 连接设置

| 设置 | 填写方式 |
| --- | --- |
| 服务器地址 | 你自己的 OpenCode HTTPS 地址，例如 `https://opencode.example.com`；新安装默认留空 |
| 用户名 | `opencode` |
| 登录密码 | 现有 OpenCode 登录密码；由用户在本机填写 |
| 服务器项目目录 | `/workspace` |
| 服务器笔记根目录 | `/workspace/vault` |

密码保存在本机 `.obsidian/plugins/obsb-chat/data.json` 中，不包含在插件安装包或 Git 中。不要填写 DeepSeek API Key。修改设置后在聊天面板点击“刷新”。点击左侧聊天图标，或运行命令“OBSB AI 管家：打开 AI 管家”。输入框支持 Enter 发送、Shift+Enter 换行，兼容 Ctrl/⌘+Enter 发送；中文输入法组合输入及选词确认不会触发发送。手机也可使用发送按钮。
