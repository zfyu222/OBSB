## 框选与批量操作

- 空白处按住左键拖出选框，以节点可见矩形与选框相交为选中条件；使用视口坐标，兼容缩放、滚动和反向拖动。折叠后不可见的后代不单独框选，但会随父节点子树复制/移动/删除。
- Ctrl/Cmd/Shift 加框选追加选中节点，配合单击切换节点选中状态；普通单击回到单选。
- 鼠标中键拖动画布。左键框选不会平移；节点拖动也不会误触发画布平移。
- Delete/Backspace 删除所选子树；Ctrl/Cmd+C 复制；选中目标后 Ctrl/Cmd+V 将多棵子树按原 Markdown 顺序粘贴到目标下。
- 从任意选中节点开始拖动，可整组移动到目标的子节点或同级位置；Ctrl/Cmd 加拖动则复制到目标下。
- 操作前过滤所有已有选中祖先的节点。例如选中 A、A 的子节点 B、另一分支 C，实际只处理 A 和 C 两棵子树。
- 批量删除、移动、粘贴均是一次撤销/重做。根节点不能删除或移动，不能将所选子树拖入自身；编辑文字时仍按文字编辑语义处理快捷键。

## 发布流程

fork 的 `.github/workflows/plugin-release.yml` 由数字开头 tag 的 push 触发。它安装锁定依赖、校验版本、执行测试和构建、检查发布 bundle 的快捷键，将三个未压缩文件作为 GitHub Release 附件上传；带 `-beta.*` 等后缀的 tag 标记为 prerelease。无需配置额外 PAT，工作流使用仓库的 `GITHUB_TOKEN` 和 `contents: write`。

1. 用户要求发布后，选择未使用的新版本。同步 fork 的 `manifest.json`、`package.json` 和 `versions.json`；兼容表记录版本到 `minAppVersion` 的映射。依赖/版本变化后更新 lockfile。
2. 运行上述安装、测试和构建，检查待提交 diff；源码和发布配置提交至 fork，主工程的状态文档另行提交。
3. 推送已校验的发布 commit，再推送同版本 tag，例如 `0.2.6-beta.1`，不加 `v`。可从已测试的开发分支发布 beta，无须先合并 PR；不要替换已发布 tag。
4. 用 `gh run list --repo zfyu222/obsidian-enhancing-mindmap` 核验对应工作流，必要时用 `gh run view <run-id> --log-failed` 定位错误。
5. 核验 `gh release view <version> --repo zfyu222/obsidian-enhancing-mindmap --json url,tagName,isPrerelease,assets`。下载发布的 `manifest.json` 确认版本与 tag 相同，三个附件必须是 `main.js`、`manifest.json`、`styles.css`。只有核验成功后才报告 BRAT 可安装。

首次 fork 发布若 Actions 未启用，启用该 fork 的 Actions 后再发布。构建失败时修复问题并使用新 tag；若只是权限或服务暂时失败，确认没有同名 Release 后可以重跑原工作流。已存在的 Release 不自动覆盖。不能把本机成功的构建当作远端工作流成功，也不能把推送 tag 当作已上传附件。

两个插件的发布系统独立：OBSB 根目录 `manifest.json` 和 `plugins/obsb-chat/` 是 AI 管家；思维导图的三个版本文件在 fork 根目录。不要在 OBSB 上推思维导图 tag。

## BRAT 安装

1. 每个 Obsidian 客户端在社区插件中安装并启用 **BRAT**。
2. 运行 **BRAT: Add a beta plugin for testing** 或设置里的 Add Beta Plugin。
3. 输入 `zfyu222/obsidian-enhancing-mindmap`（完整 GitHub URL 也可），选择最新版本或指定 `0.2.6-beta.3`。已有用户若冻结在旧版，需要改为 beta.3 或最新版本；更新后重载插件或重启 Obsidian。
4. 在社区插件列表启用 **Enhancing Mindmap**，之后通过 BRAT 更新。

原版与 fork 的插件 ID 相同，不是两个并存的插件。已有原版时先停用，备份设备配置后由 BRAT 安装/更新同一 ID；检查安装的版本和来源。不要用社区目录的原版更新来替代 fork 更新。

Windows 与 Android 分别安装；项目当前不通过 LiveSync 同步 `.obsidian/`。本次工作只配置发布，不自动安装、修改客户端配置或同步 NAS。

BRAT 安装的是 Release 的编译附件，不是源码分支，也不会编译 PR。手动备选方式为将三个附件放到该客户端 `<vault>/.obsidian/plugins/obsidian-enhancing-mindmap/`，重载 Obsidian 后启用。
