# 知识库框架开发文档入口

本文件只在用户明确要求讨论、开发、部署或排查知识库框架时读取。日常笔记问答与编辑使用根目录 `AGENTS.md` 和按需加载的知识库 Skills，无需读取这里列出的文档。

开始规划或修改框架前，先读 [需求与方案共识](需求与方案共识.md)，确认已定决策、当前状态与尚未验证的假设。再按任务选择：

| 任务 | 按需读取 |
| --- | --- |
| 改动知识库语义规则、整理流程或 Agent 行为 | [知识库维护详细规则](知识库维护规则.md)、相关 `.opencode/skills/*/SKILL.md`、相关程序与测试 |
| 调整交付范围、验收或版本阶段 | [分期实施计划](分期实施计划.md) |
| 涉及 Obsidian 核心设置、社区插件设置或客户端权限 | [Obsidian 初始化配置](Obsidian初始化配置.md)，确认依赖后更新清单 |
| 开发 Obsidian 原生 AI 聊天插件 | [插件说明与测试边界](../plugins/obsb-chat/README.md)、`plugins/obsb-chat/src/`，服务端协议按实际部署版本核验 |
| 排查手动完整整理运行 | [完整整理故障诊断](夜间整理故障诊断.md) |
| 从 Windows 通过 SSH 执行 NAS 维护命令 | [NAS 命令执行](NAS命令执行.md)、`deploy/scripts/invoke-nas-command.ps1` |
| 回顾同步与首期服务器部署 | [第一期部署与验收](第一期部署与验收.md) |
| 讨论尚未纳入当前范围的功能 | [需求池](需求池.md) |

`docs/` 中的方案和实施记录不是日常知识库检索对象；用户若明确问项目本身，再读取相关文档。框架代码在外层 Git，笔记在 `vault/` 的内层 Git，两者分别提交。
