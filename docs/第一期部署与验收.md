# 第一期部署与验收

状态：服务器基础已部署，等待 Lucky 公网路由和客户端接入。

## 固定入口

- NAS 项目根目录：`/volume2/OBSB`（普通 Btrfs 目录，不是 DSM 共享文件夹）
- Windows vault：`H:\obsb`
- CouchDB 内网入口：`http://10.0.0.81:15984`
- LiveSync 公网入口：`https://obsync.hytzfy.dpdns.org:40087`
- 数据库：`obsidiansb`
- 长期容器：`brain-couchdb`、`brain-livesync-cli`

管理员密码、同步密码、E2EE 口令和 Setup URI 临时口令只保存在 NAS 的 `secrets/` 中，不得复制到本文、Git、聊天或普通备份。

## Lucky 配置

由用户在 Lucky 中建立规则：

- 域名：`obsync.hytzfy.dpdns.org`
- 外部端口：`40087`
- 后端：`http://10.0.0.81:15984`
- HTTPS，有效证书；不增加第二层 Basic Auth；不改写路径；关闭缓存；长连接超时至少 3600 秒。

## 服务器操作

部署：

```sh
sudo sh /tmp/obsidiansb-stage/deploy/scripts/bootstrap-nas.sh /tmp/obsidiansb-stage
```

检查：

```sh
sudo sh /volume2/OBSB/project/deploy/scripts/check-phase1-server.sh
```

软停止：

```sh
sudo /volume2/OBSB/project/bin/docker-compose \
  -f /volume2/OBSB/project/deploy/compose.yaml stop livesync-cli couchdb
```

软停止不会删除 vault、附件、Git、CouchDB 数据或秘密。
